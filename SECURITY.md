# Security Policy

## Educational & Research Scope

**docker-escape-lab** is an intentionally misconfigured and vulnerable environment designed solely
for educational training, cloud infrastructure security research, and CTF competitions.

- **Do NOT** deploy this Compose environment to production clusters, public clouds without strict firewalls, or shared developer workstations.
- **Do NOT** use the breakout techniques demonstrated here against systems or networks without prior explicit written permission.

## Reporting Security Vulnerabilities

If you discover an unintentional vulnerability that affects the safety of running this lab on an isolated workstation (e.g., unintended remote code execution from outside the local machine without user interaction), please open an issue or reach out via email: southkhanh@gmail.com.
